# 伴读（PWA）

一个纯前端的阅读伴读面板：提问、深答、随手记、问题清单、导出 Markdown。
**没有服务器、没有同步、没有账号**。数据只存在你自己浏览器的 IndexedDB 里。

## 用法

1. 安卓 Chrome 打开本页 → 菜单 →「添加到主屏幕」（iPhone Safari 同理）。
2. 第一次打开，点「设置」填 DeepSeek API Key（只存本机浏览器，直接发给模型服务商）。
3. 从 ReadAny 里复制一段阅读内容，粘到「当前阅读 / 选中」，再提问。
4. 「随手记」存想法；「导出全部 Markdown」把问答与捕获导出，回电脑导入 Obsidian / 自己的工作区。

## 隐私

- 本站是静态页面，只托管代码，不接收、不存储任何阅读内容或 Key。
- Key 与数据都在浏览器本地；换手机、清理浏览器存储前请先导出。
- 页面无第三方脚本、无统计。

## 开发

纯静态：`python3 -m http.server` 本地预览即可。

- `prompt.txt` 系统提示词（与桌面 sidecar 共用一份）
- `questions.json` 问题清单
- `sw.js` 离线缓存

## 已知限制

- 浏览器存储可能被系统清理，必须定期导出。
- 手机拿不到 ReadAny 的选中内容，只能复制粘贴。
- 浏览器直连模型依赖供应商的 CORS；DeepSeek 已验证可用。
